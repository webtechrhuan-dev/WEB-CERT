# Marca Web Tech

O arquivo original da logo não está presente no workspace. Adicione a versão
oficial, preferencialmente em SVG ou PNG com transparência, a esta pasta quando
ela estiver disponível. Exemplo de nome de arquivo: `web-tech-logo.svg`.

Use o arquivo oficial sem redesenhar, recortar ou alterar suas proporções.
Se ele for adicionado, utilize `next/image` com `width` e `height` que
correspondam à proporção original e `className` com `object-contain`.

Até a inclusão do asset oficial, o cabeçalho identifica a empresa apenas pelo
nome tipográfico “WEB TECH”; nenhum símbolo substituto foi criado.
